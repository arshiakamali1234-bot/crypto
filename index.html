تنظیمات هوش مصنوعی تکمیلی (اختیاری)

تحلیل اصلی این سایت کاملاً مبتنی بر محاسبات ریاضی واقعی روی داده‌های زنده است (بدون حدس). اگر بخواهی خروجی را به‌صورت روایت طبیعی‌تر توسط یک مدل زبانی هم بازنویسی شود، کلید API خودت را وارد کن. کلید فقط در همین مرورگر (localStorage) ذخیره می‌شود و به هیچ سروری جز API انتخابی ارسال نمی‌شود.





⚠ چون این یک سایت استاتیک روی گیت‌هاب است، هر کلیدی که اینجا وارد کنی مستقیماً از مرورگر خودت به سرور AI فراخوانی می‌شود. برای استفاده شخصی مشکلی ندارد؛ آن را با دیگران به اشتراک نگذار.
